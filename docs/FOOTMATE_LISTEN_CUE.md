# Passport C3: listen after cue playback

The existing path enables capture before playing OGG_POPUP. On this C3 without AEC, the cue can enter uplink and start server segmentation. Reuse pending_listening_start_ and the playback-drained event: stop capture/wake, reset decoder, play cue, then start listening. An already-drained/empty cue falls through immediately; a state change clears pending capture in the existing state handler. No new protocol or blocking delay.

Failure cases were recorded before implementation in football-mate/docs/PASSPORT_WAKE_PLAN.md: cue contamination, lost drain event, cancellation/state transition, premature second turn, and standby reconnect race. Full microphone correctness still requires physical acceptance.
